My Projects

JARC: Automated Jeepney Rain Cover Deployment using Arduino and Sensors

Short Description

JARC is an automated rain-cover system for jeepneys. It uses a rain sensor to detect water and an Arduino Uno to control a motor that automatically deploys the rain cover when it rains and retracts it when the rain stops.

My Role/Contribution

I contributed to the research and documentation of the project, including gathering information, organizing the research content, and helping with the evaluation of the prototype.

Technologies/Tools Used

  • Arduino Uno
  • Rain Sensor
  • DC Gear Motor
  • Survey Questionnaires
  • Observation Checklists

Applying What I Learned in IT111

Module 1: History of Computing

Development of the Personal Computer

One important development in computing history was the development of the personal computer (PC). Computers became smaller, more affordable, and accessible to individuals instead of being used only by large organizations. This development contributed to the technology we use today, including computers for programming, studying, communication, and creating websites.

Module 2: Computer Systems

How a Computer Helps Me Create My Portfolio

I use a computer to create, edit, save, and view my portfolio.

Input → Processing → Storage → Output

Input

I type HTML and CSS code using a keyboard.

Processing

The computer processes the code using a code editor and web browser.

Storage

My files are saved on the computer as HTML and CSS files.

Output

The browser displays my completed portfolio website on the screen.

Module 3: Connected World

What Happens When Someone Visits My Website?

When someone visits my portfolio, their device connects to a network and uses the Internet to access the Web. The visitor uses a browser to request the website from a server. The server sends the website files back to the browser, which displays the portfolio on the screen.

Terms Used: Network • Internet • Web • Browser • Server
